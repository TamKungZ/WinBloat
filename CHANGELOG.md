# Changelog

## [0.2.1] - 2026-10-08

### Changed
- Release downloads are limited to combined portable ZIP bundles and setup installers; standalone CLI/GUI executables, winget manifests, and Store MSIX packages are no longer published.
- Documented that development focuses on the CLI and the GUI is experimental.

## [0.2.0] - 2026-10-08

### Added
- Native window with searchable file tree, item details, treemap, and file-type summary.
- CLI summaries for large directories and file types.
- x64, x86, and ARM64 installers and portable ZIPs.
- Detached GPG signatures for release files.

### Changed
- CLI and GUI report read-only scanning and logical file sizes.

## [0.1.0] - 2026-10-08

### Added
- Initial Windows disk scanner with CLI and terminal tree browser.
- Largest-file, recently accessed file, directory tree, and scan memory summaries.
